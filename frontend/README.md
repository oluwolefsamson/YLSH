# YLSH

YLSH is a youth platform and event operating system for identity verification, registrations, attendance, certificates, mentorship, learning resources, opportunities, and analytics.

It is designed to help youth programs and organizations manage participation in one place instead of juggling separate tools for onboarding, events, and reporting.

## What It Showcases

- Identity verification with NIN support
- Event registration and attendance workflows
- Audit-ready role-based access control
- Certificate generation with QR verification
- Mentorship, learning, and opportunity discovery
- Analytics for participation and engagement

## Built With

- Next.js
- React
- Material UI
- TypeScript

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Project Vision

YLSH is built to be a free, structured platform for youth programs, events, and community operations. The goal is to make it easier to verify users, run events, issue certificates, and track participation from a single dashboard.
